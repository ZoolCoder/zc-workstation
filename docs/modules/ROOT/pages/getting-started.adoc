= Getting started
:description: Install zc-workstation and the tools it drives on macOS, Linux or Windows, then plan and apply.

== Install the tools it drives

`zc-workstation` runs your package manager, chezmoi and mise. Install the
ones your config uses. A missing one shows up in the plan as a `MANUAL` step,
so you can also start with `plan` and follow it.

[tabs]
====
macOS::
+
[source,console]
----
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
$ brew install chezmoi mise mas
----

Ubuntu and Debian::
+
[source,console]
----
$ sudo apt-get install -y curl git
$ sh -c "$(curl -fsLS get.chezmoi.io)" -- -b ~/.local/bin
$ curl https://mise.run | sh
----

Fedora::
+
[source,console]
----
$ sudo dnf install -y chezmoi git
$ curl https://mise.run | sh
----

Windows::
+
[source,powershell]
----
PS> winget install --id twpayne.chezmoi --exact
PS> winget install --id jdx.mise --exact
----
====

== Install zc-workstation

The Homebrew cask, Linux packages and Windows zips come with each release.
Before the first one, install with Go, or run `make install` in a clone.

[tabs]
====
Homebrew::
+
[source,console]
----
$ brew tap zoolcoder/zc-workstation https://github.com/zoolcoder/zc-workstation
$ brew install --cask zc-workstation
----

Linux packages::
+
Each release has `.deb`, `.rpm` and `.apk` packages.
+
[source,console]
----
$ sudo apt-get install ./zc-workstation_*_linux_amd64.deb
----

Windows::
+
Download the `windows_amd64` or `windows_arm64` zip from the releases page and
put `zc-workstation.exe` on your `PATH`.

Go::
+
[source,console,subs=attributes+]
----
$ go install github.com/zoolcoder/zc-workstation/cmd/zc-workstation@latest
----
+
Needs Go {go-version} or later.
====

== Write a config

Start from `zc-workstation.example.yaml`. It declares a target for each system
and points at the sample manifests in `example/`. Point it at your own dotfiles
repository instead. xref:configuration.adoc[Writing a config] lists every key.

[source,console]
----
$ mkdir -p ~/.config/zc-workstation
$ cp zc-workstation.example.yaml ~/.config/zc-workstation/zc-workstation.yaml
$ zc-workstation validate
/Users/me/.config/zc-workstation/zc-workstation.yaml: 6 target(s), valid
----

== Plan, then apply

[source,console]
----
$ zc-workstation plan -out plan.json
CREATE  brew      brew:chezmoi  install with brew
CREATE  dotfiles  .gitconfig    add
MANUAL  runtimes  trust         mise does not trust .../mise.toml; review it, then run mise trust .../mise.toml

1 of these cannot be automated and are yours to do.
$ zc-workstation apply plan.json
done  CREATE brew brew:chezmoi
done  CREATE dotfiles .gitconfig
applied and verified
----

Installs run attached to your terminal, so `sudo`, a license prompt or the App
Store sign-in can ask you directly.
